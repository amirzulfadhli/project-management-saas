# Changelog 

All notable changes to FlowPlan are documented in this file. 

The project is actively developed, so unreleased changes may be grouped under 
the `Unreleased` section until a versioned release is created. 

## [Unreleased] 

### Added 

- Email/password authentication and cookie-backed sessions.
- Organization onboarding and workspace selection.
- Organization OWNER/MEMBER administration.
- Organization-scoped project lifecycle.
- Project membership and role administration.
- Single-board Kanban workflow with managed columns.
- Task creation, editing, assignment, ordering, and deletion.
- Project activity history.
- Task comments and threaded replies.
 - Comment editing, moderation, and tombstone behavior.

### Changed 

- Continued refinement of project, task, membership, and authorization
  behavior.

### Security 

- Authentication and authorization hardening continues as part of active
  development.
- Security findings and fixes will be documented here when applicable.
